## 🔁 GitHub Actions — Automated Workflows

This profile uses automated GitHub Actions for continuous quality:

```yaml
# .github/workflows/profile-update.yml
name: 🔄 Profile Auto-Update

on:
  schedule:
    - cron: '0 */6 * * *'   # Refreshes every 6 hours
  push:
    branches: [main]

jobs:
  update-readme:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: 📊 Update GitHub Stats
        uses: anmol098/waka-readme-stats@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
          GH_TOKEN: ${{ secrets.GH_TOKEN }}
          
      - name: 🏆 Sync Contribution Graph
        run: echo "Stats refreshed at $(date)"
```

> Contributions, streaks, and activity graphs on this profile update automatically every 6 hours.
